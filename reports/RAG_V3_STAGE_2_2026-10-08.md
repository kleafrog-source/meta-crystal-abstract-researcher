## Изменения

- `python_engine/anchoring_v3/build_value_anchors.py`: добавлен инкрементальный, возобновляемый builder бинарных Range/Select артефактов с SHA-256 и memory-map.
- `python_engine/anchoring_v3/config.json`, `src/lib/rag-v3/config.ts`: зафиксированы согласованные thresholds, temperatures и будущие relation/Sinkhorn flags.
- `python_engine/anchoring_v3/bridge.py`: Range и Select binary открываются через `numpy.memmap` при каждом автономном bridge-вызове.
- `python_engine/anchoring_v3/anchoring.py`: после L0 numeric/option preempt добавлен cosine + softmax/interpolation для Range и top-1 cosine для Select; надёжный lexical/description direction имеет приоритет перед факторизованным fallback.
- `src/lib/rag-v3/value-index.ts`: Select option index участвует в retrieval до запуска Python anchoring.
- `src/lib/rag-v3/search.ts`: точные Select-опции всегда включают соответствующие параметры в candidate set; добавлен n-gram lexical score для low/high-фраз descriptions.
- `python_engine/tests/test_anchoring_v3_persistent_vectors.py`: добавлены тесты Range interpolation и Select top-1.

## Формат и инкрементальность

Основные файлы:

- `value-anchors/manifest.json` + `embeddings.f32`;
- `value-anchors/select-options.json` + `select-options.f32`;
- `range-prototypes.*` и `option-prototypes.*` для повторного использования.

Каждый manifest содержит `text_sha256`, `row_index`, mapping по `technical_name` и общий cache SHA. Повторный запуск без изменений завершился за 4.3 секунды без embedding новых строк.

На текущем ПК прямой Qwen embedding полного текста всех 27985 точек был измерен на первом batch: 64 строки заняли около 120 секунд, то есть полная сборка потребовала бы примерно 14.5 часа. Поэтому рабочий артефакт построен в факторизованном Qwen-режиме:

- persistent Qwen parameter vector + Qwen state prototype для Range;
- persistent Qwen parameter vector + Qwen centroid параметров с данной опцией для Select;
- после сложения каждая строка нормализуется и сохраняется отдельным 2560-D вектором.

Таким образом runtime по-прежнему выбирает значение cosine-сходством в Qwen-пространстве, но builder остаётся практичным для RX570. Флаг `--direct` сохраняет возможность полной прямой векторизации каждого текста на более быстром оборудовании без изменения runtime-формата.
