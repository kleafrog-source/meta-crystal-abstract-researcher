## Изменения

- `python_engine/anchoring_v3/bridge.py`: composite vectors открываются через `numpy.memmap`; `technical_name` сопоставляется с постоянным row index; `a_home` загружается из live anchors.
- `python_engine/anchoring_v3/anchoring.py`: `_param_eid` возвращает persistent vector и `a_home` без embedding-вызова; `_axis_delta` использует позицию query относительно сохранённого дома параметра.
- `python_engine/anchoring_v3/build_anchors.py`: neutral calibration сначала собирает все raw deltas, ограничивает κ по 95-му процентилю, затем считает реальные остаточные нарушения.
- `python_engine/build-genesis-v3-composite-index.py`: всем параметрам присваивается один из пяти `retrieval_scope`; scope сохраняется в dataset и composite rows.
- `src/lib/rag-v3/search.ts`: кандидаты фильтруются по scope до cosine ranking.
- `src/store/rag-v3-store.ts`, `src/components/rag-v3/SemanticSearch.tsx`: добавлены сохраняемые переключатели scope; default — `sound + structure`.
- `python_engine/tests/test_anchoring_v3_persistent_vectors.py`: проверены memory-map и отсутствие скрытого embedding-вызова из `_param_eid`.
- audit-скрипты теперь поддерживают именованные фазы и записывают среднее время запроса.

- Value anchors, Select option embeddings, multi-vector retrieval и relation anchors намеренно не входят в этап 1.
- Text/String/Array продолжают retrieval-only/default политику до этапа 3.
