## 1. Расширение системы пайплайнов

Ваш существующий пайплайн‑движок (`src/lib/engine/pipeline_engine.ts` + `python_engine/sidecar.py`) позволяет выполнять цепочки действий (генерация, обогащение, эмбеддинги и т.д.). Мы добавим **новые шаги**, которые:

- используют уже готовую функциональность **Notes** (аннотации, заметки, мета‑описания кристаллов),
- вызывают LLM для генерации интерпретаций, резюме, связей,
- автоматически выбирают кристаллы для обработки (без ручного ввода ID),
- в дальнейшем интегрируются с GW‑Collapser.

### 1.1. Способы выбора кристаллов для пайплайна

Чтобы не вводить ID вручную, каждый пайплайн должен принимать **режим выбора** (`selection_mode`):

- **`random`** — выбирает случайные N кристаллов из библиотеки.
- **`sequential`** — обрабатывает кристаллы по порядку их создания/изменения (можно с пагинацией).
- **`missing_interpretation`** — выбирает только те кристаллы, у которых отсутствует поле `interpretation` (или оно пустое/невалидное). Это позволит автоматически заполнять пробелы.
- **`by_tag`** — выбирает кристаллы с определённым тегом (например, `physics`, `philosophy`).
- **`by_query`** — выбирает кристаллы, релевантные текстовому запросу (через эмбеддинги).

Эти режимы можно комбинировать с ограничением `limit` и сортировкой.

## 3. Как это реализовать в коде

### 3.1. Добавление новых типов шагов в `pipeline_engine.ts`

В существующий маппер шагов нужно добавить новые записи, например:

```typescript
// src/lib/engine/pipeline_engine.ts
const stepHandlers: Record<string, StepHandler> = {
  // ... существующие (generate, enrich, embed, ...)
  'generate_notes_summary': async (params, context) => {
    const { selection_mode, limit = 10 } = params;
    const crystals = await selectCrystals(selection_mode, limit);
    for (const crystal of crystals) {
      const summary = await callLLM(`Summarize: ${crystal.content}`);
      await addNote(crystal.id, summary);
    }
    return { processed: crystals.length };
  },
  // ... и так для каждого нового шага
};
```

### 3.2. Функция выбора кристаллов

Создадим универсальную функцию `selectCrystals(mode, params)`:

```typescript
async function selectCrystals(mode: string, params: any) {
  switch (mode) {
    case 'random':
      return prisma.crystal.findMany({ take: params.limit, orderBy: { id: 'asc' }, skip: randomOffset });
    case 'sequential':
      return prisma.crystal.findMany({ take: params.limit, orderBy: { createdAt: 'asc' } });
    case 'missing_interpretation':
      return prisma.crystal.findMany({ where: { interpretation: null }, take: params.limit });
    // ...
  }
}
```

### 3.3. Интеграция с GW‑Collapser в пайплайне

Шаг `run_torus_analysis` будет вызывать Python‑модуль через sidecar, передавая ему содержимое кристалла и запрос (который может быть взят из параметров пайплайна или из поля `query` кристалла). Результат сохраняется в поле `crystal.torusData`.
