# Readme SVG icons

These static icons are used by the root README and mode cards. Mode shapes match the `AMIcon` paths used by the primary sidebar; their strokes use the regular (not hovered/active) sidebar palette from `src/app/globals.css`. Legacy shapes are rendered from the Lucide components used by `src/components/layout/Sidebar.tsx`. `am-core.svg` is a static rendering of the sidebar `AMCoreLogo` at its default state.

If a sidebar icon or its normal-state color changes, update its matching SVG here as well.
