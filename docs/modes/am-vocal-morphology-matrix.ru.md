# <img src="../assets/readme-icons/am-vocal-morphology-matrix.svg" alt="" width="96" height="96" align="absmiddle" /> AM-Vocal Morphology Matrix

Структурированный поиск вокальных параметров по каталогу: [`/am-vocal-morphology-matrix`](http://localhost:3000/am-vocal-morphology-matrix).

- Ввод описания вокала и необязательных языковых тегов, техник и эффектов.
- Просмотр распознанных критериев и найденных контролов параметров.
- Редактирование найденных значений; при наличии показываются последние форманты из AM-Stage.
