# <img src="../assets/readme-icons/am-stage.svg" alt="" width="96" height="96" align="absmiddle" /> AM Tri-Modal Stage

Рабочая среда сессии для поиска параметров по тексту, аудио и спектрограммам.

- **Work Axis:** загрузка аудиосессии, просмотр waveform/спектрограммы, переход по времени и узлам анализа.
- **Extract:** Semantic Search Brief, анализ CLAP/SigLIP2 и включённые аудио-/текстовые специалисты.
- **Reconcile:** маска из девяти слоёв, сглаживание на клиенте или поиск Server Stage-2, предпросмотр межмодальной интерполяции.
- **Project:** отдельные текстовые банки Qwen и Gemma, банки модальностей, временная шкала и экспорт макроса/текстовых признаков.
- Результаты идентификации Gemma и прохода по значениям разделены; возможность Gemma для спектрограмм выключена по умолчанию.
- Состояние и перестройка индексов находятся в [Service Bay](service-bay.ru.md), а не в Stage.

См. [контракт Stage в формате MMSS](../mmss-modes/am-tri-modal-stage.mmss.json).
