# <img src="../assets/readme-icons/audio-clap-rag.svg" alt="" width="96" height="96" align="absmiddle" /> Audio CLAP RAG

Retrieve parameter candidates from an audio query at [`/audio-clap-rag`](http://localhost:3000/audio-clap-rag).

- Load audio, select a time range and submit it to the CLAP search path.
- Review ranked catalogue candidates and their parameter controls.
- Save and reopen audio fragments in the local workflow.
- CLAP index status and rebuild controls are available in [Service Bay](service-bay.md).
