# Combinatorial Synthesis

Создание и проверка новых комбинаций параметров: [`/combinatorial-synthesis`](http://localhost:3000/combinatorial-synthesis).

- Укажите имена параметров-источников и смысловую цель для поиска кандидатов.
- Проверьте созданные предложения, выведенные метаданные контролов и необязательную нормализацию текста.
- Выберите кандидатов для публикации после проверок схемы и подтверждения на странице.
