# <img src="../assets/readme-icons/am-stage.svg" alt="" width="36" height="36" align="absmiddle" /> AM Tri-Modal Stage

The session workbench for text, audio and spectrogram-oriented parameter retrieval.

- **Work Axis:** attach session audio, inspect waveform/spectrogram, navigate time and analysis nodes.
- **Extract:** run Semantic Search Brief, CLAP/SigLIP2 analysis and enabled audio/text specialists.
- **Reconcile:** choose a nine-layer mask, use client smoothing or server Stage-2 retrieval, and preview cross-modal interpolation.
- **Project:** review separate Qwen and Gemma text banks, modality banks, timeline and macro/text exports.
- Gemma text/audio identity and value-pass results are distinct; Gemma spectrogram capability is disabled by default.
- Index status and rebuild controls live in [Service Bay](service-bay.md), not in Stage.

See the [Stage MMSS contract](../mmss-modes/am-tri-modal-stage.mmss.json).
