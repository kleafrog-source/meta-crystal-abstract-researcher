# <img src="../assets/readme-icons/parameter-catalogue.svg" alt="" width="96" height="96" align="absmiddle" /> Parameter Catalogue

Maintain the published parameter library at [`/am-parameters-catalogue`](http://localhost:3000/am-parameters-catalogue).

- Search, filter and inspect parameter records, domains and completeness.
- Add, edit, import or delete through the change queue; changes are applied only after confirmed commit.
- Export filtered or full catalogue data.
- A confirmed catalogue commit marks dependent indexes dirty; it does not start embedding rebuilds.
