# <img src="../assets/readme-icons/parameter-catalogue.svg" alt="" width="96" height="96" align="absmiddle" /> Каталог параметров

Управление опубликованной библиотекой параметров: [`/am-parameters-catalogue`](http://localhost:3000/am-parameters-catalogue).

- Поиск, фильтрация и просмотр записей, доменов и полноты данных.
- Добавление, редактирование, импорт и удаление через очередь; изменения применяются только после подтверждённого commit.
- Экспорт отфильтрованных данных или всей библиотеки.
- Подтверждённый commit каталога помечает зависимые индексы устаревшими, но не запускает построение embeddings.
