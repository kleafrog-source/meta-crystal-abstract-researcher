# <img src="../assets/readme-icons/am-core-engine.svg" alt="" width="96" height="96" align="absmiddle" /> AM-Core Engine

Focused text retrieval and parameter review at [`/am-core`](http://localhost:3000/am-core).

- Search with a single text query or a transition between two states.
- Select retrieval scopes and instruction settings; choose the available text index.
- Review and edit the returned parameter controls, then use Clean Macro output.
- Open index status and manual rebuilds in [Service Bay](service-bay.md).
