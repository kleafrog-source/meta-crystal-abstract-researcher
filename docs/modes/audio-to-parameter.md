# <img src="../assets/readme-icons/audio-to-parameter.svg" alt="" width="96" height="96" align="absmiddle" /> Audio-to-Parameter

Create a time-based analysis of an audio file at [`/audio-to-parameter-rag-segments`](http://localhost:3000/audio-to-parameter-rag-segments).

- Configure sampling and node/window placement, then run analysis over selected audio intervals.
- Inspect segment results against waveform and spectrogram context.
- Continue or rerun analysis and review the resulting parameter timeline.
- Index readiness is shown in the mode; index maintenance is in [Service Bay](service-bay.md).
