# Combinatorial Genesis

Review and process candidate material for combinatorial workflows at [`/combinatorial-genesis`](http://localhost:3000/combinatorial-genesis).

- Inspect inbox material, collections and candidate records.
- Run the available collection/pipeline operations and review their results.
- Preview and publish approved combinations; publication does not make a generated corpus the parameter catalogue.
- The published parameter library remains managed in [Parameter Catalogue](parameter-catalogue.md).
