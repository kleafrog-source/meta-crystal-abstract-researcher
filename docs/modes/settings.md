# Settings

Configure application-wide preferences and model capabilities at [`/?page=settings`](http://localhost:3000/?page=settings).

- Choose interface language and appearance; set the parameter title order.
- Configure model IDs, providers and enablement for embedding, language, audio and local analysis slots.
- Enable or disable product banks and optional capabilities.
- Persist changes with **Save**; the active runtime model values may differ from defaults.
