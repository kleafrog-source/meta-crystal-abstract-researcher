# Research modes

Three additional analysis routes are available in the primary sidebar.

## White Space Discovery
- Build and inspect a report about sparse or uncovered regions using existing catalogue-derived artifacts.
- This analysis does not publish parameter records.

## Knowledge Graph
- Build a graph from catalogue taxonomy/atoms and semantic-neighbor data.
- Inspect parameter neighbors and graph summaries.

## Cross-Modal Consensus
- Review journaled audio/image retrieval records and their reverse-query checks.
- Build/use the shared bridge and run consensus or transition operations on selected records.
