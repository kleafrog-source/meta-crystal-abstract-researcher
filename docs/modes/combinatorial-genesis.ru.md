# <img src="../assets/readme-icons/combinatorial-genesis.svg" alt="" width="96" height="96" align="absmiddle" /> Combinatorial Genesis

Проверка и обработка кандидатных данных для комбинаторных процессов: [`/combinatorial-genesis`](http://localhost:3000/combinatorial-genesis).

- Просмотр inbox, коллекций и кандидатных записей.
- Запуск доступных операций над коллекциями/пайплайном и проверка результатов.
- Предпросмотр и публикация одобренных комбинаций; сгенерированный корпус не становится каталогом параметров.
- Опубликованная библиотека параметров обслуживается в [Каталоге параметров](parameter-catalogue.ru.md).
