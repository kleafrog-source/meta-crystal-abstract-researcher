# <img src="../assets/readme-icons/am-core-engine.svg" alt="" width="28" height="28" align="absmiddle" /> AM-Core Engine

Режим текстового поиска и проверки параметров по адресу [`/am-core`](http://localhost:3000/am-core).

- Поиск по одному текстовому запросу или переходу между двумя состояниями.
- Выбор области поиска, инструкций и доступного текстового индекса.
- Просмотр и настройка найденных параметров, затем подготовка Clean Macro.
- Состояние индексов и ручная перестройка находятся в [Service Bay](service-bay.ru.md).
