# Audio-to-Parameter

## Назначение

`/audio-to-parameter-rag-segments` строит воспроизводимую временную линию параметров V3 по аудиотреку. В отличие от Audio CLAP RAG, который анализирует один выбранный фрагмент, этот режим автоматически делит трек на узлы и показывает изменение результата во времени.

## Рабочий процесс

1. Пользователь загружает локальный аудиофайл.
2. WaveSurfer отображает waveform, minimap и синхронизированную спектрограмму.
3. Интервал задаёт расстояние между временными узлами. Если трек короче выбранного интервала, создаются начальная и конечная точки.
4. Сегменты обрабатываются последовательно. Пакет можно остановить; уже готовые узлы сохраняются в интерфейсе.
5. Для каждого узла строится изображение спектрограммы и выполняется Morpho/SigLIP2 retrieval по V3. Дополнительные сигналы и Vocal Allocation Matrix включаются настройками режима.
6. Результаты объединяются по `technical_name`, затем значения Range сглаживаются между соседними узлами. Select/Toggle меняются дискретно в точках перехода.
7. Во время playback текущая позиция WaveSurfer выбирает соответствующий участок таймлайна и обновляет панель параметров.

## Приоритеты результата

- Явный результат текущего узла имеет приоритет над переносом предыдущего значения.
- При совпадении параметра учитываются retrieval score, источник сигнала и стабильность в соседних узлах.
- Range допускает весь валидный диапазон параметра; финальное значение ограничивается `min_value`/`max_value` и приводится к `step`.
- Select использует только варианты из `options`, Toggle — булево значение.
- Параметр без достаточного сигнала не получает произвольное значение: используется политика выбранного режима и, при необходимости, default.

## Представления спектрограммы

Интерфейс позволяет менять детализацию визуализации. Для SigLIP2 формируется отдельный RGB-признак: каналы кодируют спектральную структуру и изменение энергии, а не скриншот DOM. Это делает batch-поиск независимым от масштаба браузера и позиции прокрутки.

## Управление ресурсами

Сегменты не запускаются параллельно. Перед мультимодальным поиском приложение останавливает загруженные Ollama-модели и ждёт освобождения памяти. Кнопка остановки прекращает новые задачи и отправляет отмену активному процессу; готовые результаты не удаляются.

## Связанные режимы

- `/audio-clap-rag` — один аудиофрагмент → CLAP text index V3.
- `/morpho-acoustic-rag` — изображение/спектрограмма → SigLIP2 index V3.
- `/vocal-allocation-matrix` — специализированный разбор языков, вокальных техник, FX и слоёв.
- `/rag-parameters-v3` — применение результата в панели Genesis V3 и экспорт Clean Macro.

## Обновление индексов

После пополнения V3 сначала завершите Combinatorial Genesis pipeline. Затем отдельно обновите CLAP и SigLIP2 индексы. Индекс хранит имя embedding-модели; поиск не должен смешивать векторы разных моделей или размерностей.
